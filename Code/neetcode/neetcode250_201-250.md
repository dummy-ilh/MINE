### 201. Path With Maximum Probability
**Problem:** Find the path between two nodes maximizing the product of edge probabilities.
**Sample I/O:** `n=3, edges=[[0,1],[1,2],[0,2]], succProb=[0.5,0.5,0.2], start=0, end=2` → `0.25`
```python
import heapq
from collections import defaultdict
def maxProbability(n, edges, succProb, start, end):
    graph = defaultdict(list)
    for (a,b), p in zip(edges, succProb):
        graph[a].append((b,p)); graph[b].append((a,p))
    maxHeap = [(-1.0, start)]
    seen = set()
    while maxHeap:
        prob, node = heapq.heappop(maxHeap)
        prob = -prob
        if node == end: return prob
        if node in seen: continue
        seen.add(node)
        for nei, p in graph[node]:
            if nei not in seen:
                heapq.heappush(maxHeap, (-(prob*p), nei))
    return 0.0
```
**Alternative (Bellman-Ford style relaxation, simpler but slower):**
```python
from collections import defaultdict
def maxProbability(n, edges, succProb, start, end):
    graph = defaultdict(list)
    for (a,b), p in zip(edges, succProb):
        graph[a].append((b,p)); graph[b].append((a,p))
    prob = [0.0]*n
    prob[start] = 1.0
    for _ in range(n-1):
        for a in range(n):
            for b, p in graph[a]:
                if prob[a]*p > prob[b]: prob[b] = prob[a]*p
    return prob[end]
```
**Dry run:** Dijkstra-style max-heap: `0→1` (prob 0.5), `0→2` direct (prob 0.2); path `0→1→2` gives `0.5*0.5=0.25 > 0.2` → answer `0.25`.

### 202. Find the City With the Smallest Number of Neighbors at a Threshold Distance
**Problem:** Given a weighted graph, find the city with the fewest reachable cities within a distance threshold (ties → largest city number).
**Sample I/O:** `n=4, edges=[[0,1,3],[1,2,1],[1,3,4],[2,3,1]], distanceThreshold=4` → `3`
```python
def findTheCity(n, edges, distanceThreshold):
    dist = [[float('inf')]*n for _ in range(n)]
    for i in range(n): dist[i][i] = 0
    for a, b, w in edges:
        dist[a][b] = w; dist[b][a] = w
    for k in range(n):
        for i in range(n):
            for j in range(n):
                if dist[i][k]+dist[k][j] < dist[i][j]:
                    dist[i][j] = dist[i][k]+dist[k][j]
    best, bestCount = -1, float('inf')
    for i in range(n):
        count = sum(1 for j in range(n) if i != j and dist[i][j] <= distanceThreshold)
        if count <= bestCount:
            bestCount = count
            best = i
    return best
```
**Alternative:** run Dijkstra from every node individually instead of Floyd-Warshall — better for sparse graphs (O(n*(E log V))) vs O(n^3), but more code.
**Dry run:** Floyd-Warshall computes all-pairs shortest distances; city 3 has fewest cities within distance 4 (ties broken by largest index) → `3`.

### 203. Critical Connections in a Network (Bridges)
**Problem:** Find all bridges (edges whose removal disconnects the graph) in an undirected graph.
**Sample I/O:** `n=4, connections=[[0,1],[1,2],[2,0],[1,3]]` → `[[1,3]]`
```python
def criticalConnections(n, connections):
    graph = {i: [] for i in range(n)}
    for a, b in connections:
        graph[a].append(b); graph[b].append(a)
    disc = [-1]*n
    low = [-1]*n
    timer = [0]
    res = []
    def dfs(node, parent):
        disc[node] = low[node] = timer[0]
        timer[0] += 1
        for nei in graph[node]:
            if nei == parent: continue
            if disc[nei] == -1:
                dfs(nei, node)
                low[node] = min(low[node], low[nei])
                if low[nei] > disc[node]:
                    res.append([node, nei])
            else:
                low[node] = min(low[node], disc[nei])
    dfs(0, -1)
    return res
```
**Alternative:** for each edge, temporarily remove it and run a connectivity check (DFS/BFS count of reachable nodes) — correct but O(E*(V+E)) instead of O(V+E).
**Dry run:** Tarjan's bridge-finding assigns discovery/low-link times; edge `(1,3)` is a bridge because node 3 (a leaf) has no back-edge to an ancestor of `1` → `low[3] > disc[1]` → reported.

### 204. Is Graph Bipartite?
**Problem:** Determine if a graph can be 2-colored such that no adjacent nodes share a color.
**Sample I/O:** `graph=[[1,3],[0,2],[1,3],[0,2]]` → `True`
```python
def isBipartite(graph):
    color = {}
    def dfs(node, c):
        color[node] = c
        for nei in graph[node]:
            if nei in color:
                if color[nei] == c: return False
            elif not dfs(nei, 1-c):
                return False
        return True
    for node in range(len(graph)):
        if node not in color:
            if not dfs(node, 0): return False
    return True
```
**Alternative (BFS coloring, level by level):**
```python
from collections import deque
def isBipartite(graph):
    color = {}
    for start in range(len(graph)):
        if start in color: continue
        color[start] = 0
        q = deque([start])
        while q:
            node = q.popleft()
            for nei in graph[node]:
                if nei not in color:
                    color[nei] = 1 - color[node]
                    q.append(nei)
                elif color[nei] == color[node]:
                    return False
    return True
```
**Dry run:** color node0=0; neighbors 1,3 get color1; neighbor of 1 (node2) gets color0; node2's neighbors (0,3) already colored consistently → no conflicts → `True`.

### 205. Shortest Path Visiting All Nodes
**Problem:** Shortest path length that visits every node at least once (can revisit nodes/edges), starting from any node.
**Sample I/O:** `graph=[[1,2,3],[0],[0],[0]]` → `4`
```python
from collections import deque
def shortestPathLength(graph):
    n = len(graph)
    if n == 1: return 0
    full = (1 << n) - 1
    q = deque()
    visited = set()
    for i in range(n):
        q.append((i, 1 << i, 0))
        visited.add((i, 1 << i))
    while q:
        node, mask, dist = q.popleft()
        if mask == full: return dist
        for nei in graph[node]:
            nextMask = mask | (1 << nei)
            if (nei, nextMask) not in visited:
                visited.add((nei, nextMask))
                q.append((nei, nextMask, dist+1))
    return -1
```
**Alternative:** Floyd-Warshall all-pairs shortest paths + DP over subsets (Held-Karp style), treating this as a variant of the Traveling Salesman Problem — more setup but conceptually connects to TSP DP.
**Dry run:** BFS over (node, visited-bitmask) states starting from every node simultaneously; shortest path found visits node0 then all three leaves and back, total path length `4`.

### 206. Satisfiability of Equality Equations
**Problem:** Given equations like `"a==b"` and `"b!=c"`, determine if they can all be satisfied simultaneously.
**Sample I/O:** `["a==b","b!=a"]` → `False`
```python
def equationsPossible(equations):
    parent = {}
    def find(x):
        parent.setdefault(x, x)
        while parent[x] != x:
            parent[x] = parent[parent[x]]
            x = parent[x]
        return x
    def union(a, b):
        ra, rb = find(a), find(b)
        if ra != rb: parent[ra] = rb
    for eq in equations:
        if eq[1] == '=':
            union(eq[0], eq[3])
    for eq in equations:
        if eq[1] == '!':
            if find(eq[0]) == find(eq[3]): return False
    return True
```
**Alternative:** build an adjacency graph for `==` pairs, run connected-components via DFS/BFS instead of Union-Find, then check `!=` pairs against component membership — same result, different structure.
**Dry run:** union `a,b` (equal); then check `b!=a`: `find(b)==find(a)` (same component) → contradiction → `False`.

### 207. Most Stones Removed with Same Row or Column
**Problem:** Max stones that can be removed such that each removed stone shares a row or column with another remaining stone.
**Sample I/O:** `stones=[[0,0],[0,1],[1,0],[1,2],[2,1],[2,2]]` → `5`
```python
def removeStones(stones):
    parent = {}
    def find(x):
        parent.setdefault(x, x)
        while parent[x] != x:
            parent[x] = parent[parent[x]]
            x = parent[x]
        return x
    def union(a, b):
        parent[find(a)] = find(b)
    for r, c in stones:
        union(('r', r), ('c', c))
    return len(stones) - len({find(('r', r)) for r, c in stones})
```
**Alternative (DFS/BFS connected components treating stones as graph nodes connected if same row/col):** build a graph where stones sharing a row or column are connected, count connected components via flood fill, answer = `total stones - number of components`.
**Dry run:** union row/col identifiers for each stone; all 6 stones end up connected into a single component (rows 0,1,2 and cols 0,1,2 all chain together) → answer `6-1=5`.

### 208. Smallest String With Swaps
**Problem:** Given pairs of indices that can be swapped any number of times, return the lexicographically smallest string achievable.
**Sample I/O:** `s="dcab", pairs=[[0,3],[1,2]]` → `"bacd"`
```python
def smallestStringWithSwaps(s, pairs):
    n = len(s)
    parent = list(range(n))
    def find(x):
        while parent[x] != x: parent[x] = parent[parent[x]]; x = parent[x]
        return x
    def union(a, b):
        ra, rb = find(a), find(b)
        if ra != rb: parent[ra] = rb
    for a, b in pairs: union(a, b)
    groups = {}
    for i in range(n): groups.setdefault(find(i), []).append(i)
    res = list(s)
    for indices in groups.values():
        chars = sorted(res[i] for i in indices)
        for i, c in zip(sorted(indices), chars):
            res[i] = c
    return ''.join(res)
```
**Alternative (DFS/BFS connected components instead of Union-Find, same grouping logic):** build adjacency list from pairs, flood-fill to find connected index groups, sort characters within each group and reassign.
**Dry run:** indices `{0,3}` connected, `{1,2}` connected; sort chars within each group: group{0,3} has `d,b`→sorted `b,d`; group{1,2} has `c,a`→sorted `a,c` → result `"bacd"`.

### 209. Regions Cut By Slashes
**Problem:** Given a grid of `/`, `\`, and spaces, count the number of regions the grid is divided into.
**Sample I/O:** `[" /","/ "]` → `2`
```python
def regionsBySlashes(grid):
    n = len(grid)
    parent = list(range(4*n*n))
    def find(x):
        while parent[x] != x: parent[x] = parent[parent[x]]; x = parent[x]
        return x
    def union(a, b):
        ra, rb = find(a), find(b)
        if ra != rb: parent[ra] = rb
    for r in range(n):
        for c in range(n):
            root = 4*(r*n+c)
            top, right, bottom, left = root, root+1, root+2, root+3
            ch = grid[r][c]
            if ch == '/':
                union(top, left); union(right, bottom)
            elif ch == '\\':
                union(top, right); union(left, bottom)
            else:
                union(top, right); union(right, bottom); union(bottom, left)
            if r+1 < n: union(bottom, 4*((r+1)*n+c))
            if c+1 < n: union(right, 4*(r*n+c+1)+3)
    return sum(1 for i in range(4*n*n) if find(i) == i)
```
**Alternative:** upscale the grid 3x into a fine pixel grid representing the slashes as diagonal walls, then run a standard flood-fill / number-of-islands style count — more intuitive but higher memory use.
**Dry run:** each cell splits into 4 triangles (top/right/bottom/left); slashes union specific triangle pairs while blocking others; adjacent cells' touching triangles are unioned across cell boundaries; final connected-component count is `2`.

### 210. Design Circular Queue
**Problem:** Implement a fixed-size circular queue supporting enqueue, dequeue, front, rear, isEmpty, isFull.
**Sample I/O:** `MyCircularQueue(3)`; enQueue(1)→True; enQueue(2)→True; enQueue(3)→True; enQueue(4)→False (full)
```python
class MyCircularQueue:
    def __init__(self, k):
        self.q = [0]*k
        self.cap = k
        self.size = 0
        self.head = 0
    def enQueue(self, value):
        if self.isFull(): return False
        self.q[(self.head+self.size) % self.cap] = value
        self.size += 1
        return True
    def deQueue(self):
        if self.isEmpty(): return False
        self.head = (self.head+1) % self.cap
        self.size -= 1
        return True
    def Front(self):
        return -1 if self.isEmpty() else self.q[self.head]
    def Rear(self):
        return -1 if self.isEmpty() else self.q[(self.head+self.size-1) % self.cap]
    def isEmpty(self):
        return self.size == 0
    def isFull(self):
        return self.size == self.cap
```
**Alternative:** use Python's `collections.deque` with `maxlen=k` — much simpler, though it hides the circular-buffer mechanics being tested.
**Dry run:** after 3 enqueues, `size==cap==3` → 4th enqueue returns `False`; `Front()` returns `q[head]`, the oldest inserted value.

### 211. Design Underground System
**Problem:** Track passenger check-in/check-out times to compute average travel time between stations.
**Sample I/O:** checkIn(1,"A",3); checkOut(1,"B",8) → getAverageTime("A","B") → `5.0`
```python
class UndergroundSystem:
    def __init__(self):
        self.checkIns = {}
        self.stats = {}  # (startStation, endStation) -> [totalTime, count]
    def checkIn(self, id, stationName, t):
        self.checkIns[id] = (stationName, t)
    def checkOut(self, id, stationName, t):
        startStation, startTime = self.checkIns.pop(id)
        key = (startStation, stationName)
        total, count = self.stats.get(key, (0, 0))
        self.stats[key] = (total + (t-startTime), count+1)
    def getAverageTime(self, startStation, endStation):
        total, count = self.stats[(startStation, endStation)]
        return total / count
```
**Alternative:** store every individual trip's duration in a list per route instead of a running (total,count) tuple, computing the average on demand — uses more memory but keeps raw history.
**Dry run:** checkIn stores `(A,3)`; checkOut computes `8-3=5`, updates stats for `(A,B)` to `(5,1)`; average = `5/1=5.0`.

### 212. Insert Delete GetRandom O(1)
**Problem:** Design a data structure supporting insert, remove, and getRandom all in average O(1).
**Sample I/O:** insert(1); insert(2); remove(1); getRandom() → returns 2
```python
import random
class RandomizedSet:
    def __init__(self):
        self.vals = []
        self.idx = {}
    def insert(self, val):
        if val in self.idx: return False
        self.idx[val] = len(self.vals)
        self.vals.append(val)
        return True
    def remove(self, val):
        if val not in self.idx: return False
        i = self.idx[val]
        lastVal = self.vals[-1]
        self.vals[i] = lastVal
        self.idx[lastVal] = i
        self.vals.pop()
        del self.idx[val]
        return True
    def getRandom(self):
        return random.choice(self.vals)
```
**Alternative:** use just a plain list with linear-time `remove` (via `list.remove`) — simpler code but violates the O(1) requirement.
**Dry run:** remove(1) swaps the last element into position of `1` (so `vals` stays contiguous), updates the moved element's index, then pops the now-duplicate tail → O(1) removal maintained.

### 213. All O`one Data Structure
**Problem:** Maintain string counts supporting O(1) inc/dec/getMaxKey/getMinKey.
**Sample I/O:** inc("hello"); inc("hello"); inc("leet"); getMaxKey()→"hello"; getMinKey()→"leet"
```python
class AllOne:
    def __init__(self):
        self.count = {}
        self.countToKeys = {}  # count -> set of keys with that count
    def inc(self, key):
        oldCount = self.count.get(key, 0)
        self.count[key] = oldCount + 1
        if oldCount > 0:
            self.countToKeys[oldCount].discard(key)
        self.countToKeys.setdefault(oldCount+1, set()).add(key)
    def dec(self, key):
        oldCount = self.count[key]
        if oldCount == 1:
            del self.count[key]
        else:
            self.count[key] = oldCount - 1
            self.countToKeys.setdefault(oldCount-1, set()).add(key)
        self.countToKeys[oldCount].discard(key)
    def getMaxKey(self):
        if not self.count: return ""
        return next(iter(self.countToKeys[max(k for k,v in self.countToKeys.items() if v)]))
    def getMinKey(self):
        if not self.count: return ""
        return next(iter(self.countToKeys[min(k for k,v in self.countToKeys.items() if v)]))
```
**Alternative (doubly linked list of buckets, each bucket holding a count and set of keys, true O(1) guarantee):** maintain buckets in a linked list ordered by count, moving keys between adjacent buckets on inc/dec — avoids the O(n) scan in getMaxKey/getMinKey above.
**Dry run:** after two inc("hello") and one inc("leet"): counts are `hello:2, leet:1`; `getMaxKey` scans countToKeys for the max non-empty count (2) → `"hello"`; `getMinKey` finds min (1) → `"leet"`.

### 215. Range Sum Query - Immutable
**Problem:** Given an immutable array, answer multiple range-sum queries efficiently.
**Sample I/O:** `nums=[-2,0,3,-5,2,-1]`; sumRange(0,2)→1

```python
class NumArray:
    def __init__(self, nums):
        self.prefix = [0]*(len(nums)+1)
        for i, n in enumerate(nums):
            self.prefix[i+1] = self.prefix[i] + n
    def sumRange(self, left, right):
        return self.prefix[right+1] - self.prefix[left]
```

```python
class NumArray:
```

### 216. Range Sum Query 2D - Immutable
**Problem:** Given an immutable 2D matrix, answer multiple submatrix-sum queries efficiently.
**Sample I/O:** matrix with `sumRegion(2,1,4,3)` → `8`
```python
class NumMatrix:
    def __init__(self, matrix):
        rows, cols = len(matrix), len(matrix[0])
        self.prefix = [[0]*(cols+1) for _ in range(rows+1)]
        for r in range(rows):
            for c in range(cols):
                self.prefix[r+1][c+1] = (matrix[r][c] + self.prefix[r][c+1]
                                          + self.prefix[r+1][c] - self.prefix[r][c])
    def sumRegion(self, row1, col1, row2, col2):
        p = self.prefix
        return (p[row2+1][col2+1] - p[row1][col2+1]
                - p[row2+1][col1] + p[row1][col1])
```
**Alternative (no precomputation, sum the submatrix directly each query — O(rows*cols) per query):**
```python
class NumMatrix:
    def __init__(self, matrix):
        self.matrix = matrix
    def sumRegion(self, row1, col1, row2, col2):
        total = 0
        for r in range(row1, row2+1):
            for c in range(col1, col2+1):
                total += self.matrix[r][c]
        return total
```
**Dry run:** 2D prefix sum uses inclusion-exclusion (`bottom-right - top strip - left strip + double-counted corner`) to compute any submatrix sum in O(1).

### 217. Design Snake Game
**Problem:** Simulate a snake game on a grid: move the snake, grow it when eating food, detect collisions.
**Sample I/O:** `width=3, height=2, food=[[1,2],[0,1]]`; move("R")→0; move("D")→0; move("R")→1 (ate food)
```python
from collections import deque
class SnakeGame:
    def __init__(self, width, height, food):
        self.width, self.height = width, height
        self.food = deque(food)
        self.snake = deque([(0,0)])
        self.body = {(0,0)}
        self.score = 0
    def move(self, direction):
        r, c = self.snake[0]
        dr, dc = {"U":(-1,0),"D":(1,0),"L":(0,-1),"R":(0,1)}[direction]
        nr, nc = r+dr, c+dc
        if not (0<=nr<self.height and 0<=nc<self.width): return -1
        tail = self.snake[-1]
        self.body.discard(tail)
        if (nr,nc) in self.body: return -1
        if self.food and list(self.food[0]) == [nr,nc]:
            self.food.popleft()
            self.score += 1
            self.snake.appendleft((nr,nc))
            self.body.add((nr,nc))
            self.body.add(tail)
        else:
            self.snake.appendleft((nr,nc))
            self.snake.pop()
            self.body.add((nr,nc))
        return self.score
```
**Alternative:** represent the snake body as a plain list instead of deque+set, checking collisions via `in` on the list — simpler code, O(n) collision check instead of O(1).
**Dry run:** move "R": head goes from (0,0)→(0,1), not food → snake becomes `[(0,1)]` (moves, doesn't grow), score stays 0; later eating food at (1,2) grows the snake and increments score to 1.

### 218. Maximum Profit in Job Scheduling
**Problem:** Choose non-overlapping jobs (start, end, profit) to maximize total profit.
**Sample I/O:** `startTime=[1,2,3,3], endTime=[3,4,5,6], profit=[50,10,40,70]` → `120`
```python
import bisect
def jobScheduling(startTime, endTime, profit):
    jobs = sorted(zip(endTime, startTime, profit))
    ends = [j[0] for j in jobs]
    dp = [0]*(len(jobs)+1)
    for i, (end, start, p) in enumerate(jobs):
        idx = bisect.bisect_right(ends, start, 0, i)
        dp[i+1] = max(dp[i], dp[idx] + p)
    return dp[-1]
```
**Alternative (top-down memoized recursion on job index, choosing "take" or "skip"):**
```python
import bisect
def jobScheduling(startTime, endTime, profit):
    jobs = sorted(zip(startTime, endTime, profit))
    starts = [j[0] for j in jobs]
    memo = {}
    def dfs(i):
        if i == len(jobs): return 0
        if i in memo: return memo[i]
        skip = dfs(i+1)
        nxt = bisect.bisect_left(starts, jobs[i][1])
        take = jobs[i][2] + dfs(nxt)
        memo[i] = max(skip, take)
        return memo[i]
    return dfs(0)
```
**Dry run:** sorted by end time; job `(3,50)` and job `(3,6,70)` are compatible (job4 starts at 3, after job1 ends at 3) → `50+70=120`, the best combination.

### 219. Longest Valid Parentheses
**Problem:** Length of the longest valid (well-formed) parentheses substring.
**Sample I/O:** `")()())"` → `4` (`"()()"`)
```python
def longestValidParentheses(s):
    stack = [-1]
    best = 0
    for i, c in enumerate(s):
        if c == '(':
            stack.append(i)
        else:
            stack.pop()
```

### 221. Cherry Pickup
**Problem:** Two people start at opposite corners of a grid and move to the other corner, collecting cherries (each cell collected once); maximize total collected.
**Sample I/O:** `grid=[[0,1,-1],[1,0,-1],[1,1,1]]` → `5`
```python
def cherryPickup(grid):
    n = len(grid)
    memo = {}
    def dp(r1, c1, r2):
        c2 = r1 + c1 - r2
        if (r1<0 or c1<0 or r2<0 or c2<0 or r1>=n or c1>=n or r2>=n or c2>=n
            or grid[r1][c1]==-1 or grid[r2][c2]==-1):
            return float('-inf')
        if r1==n-1 and c1==n-1: return grid[r1][c1]
        if (r1,c1,r2) in memo: return memo[(r1,c1,r2)]
        cherries = grid[r1][c1]
        if (r1,c1) != (r2,c2): cherries += grid[r2][c2]
        best = max(
            dp(r1+1,c1,r2+1), dp(r1+1,c1,r2),
            dp(r1,c1+1,r2+1), dp(r1,c1+1,r2)
        )
        cherries += best
        memo[(r1,c1,r2)] = cherries
        return cherries
    result = dp(0,0,0)
    return max(result, 0)
```
**Alternative:** iterative bottom-up DP over `(steps, r1, r2)` states filling a 3D table forward instead of top-down memoized recursion — same recurrence, different traversal order.
**Dry run:** treat as two simultaneous paths from (0,0) to (n-1,n-1); at each synchronized step both move one step (down or right); memoized recursion explores all 4 combinations of moves, best total collected is `5`.

### 232. All Nodes Distance K in Binary Tree
**Problem:** Return all node values at distance k from a target node.
**Sample I/O:** `root=[3,5,1,6,2,0,8,null,null,7,4], target=5, k=2` → `[7,4,1]`

```python
from collections import defaultdict, deque
def distanceK(root, target, k):
    graph = defaultdict(list)
    def buildGraph(node, parent):
        if not node: return
        if parent:
            graph[node].append(parent)
            graph[parent].append(node)
        buildGraph(node.left, node)
        buildGraph(node.right, node)
    buildGraph(root, None)

    q = deque([target])

                if nei not in visited:
                    visited.add(nei)
                    q.append(nei)
        dist += 1
```

### 233. Recover Binary Search Tree
**Problem:** Exactly two nodes of a BST were swapped by mistake; recover the tree without changing its structure.

```python
        nonlocal first, second, prev
        if not node: return
        inorder(node.left)

            second = node
        prev = node
        inorder(node.right)
    inorder(root)
    first.val, second.val = second.val, first.val
```

```python
            heapq.heappush(maxHeap, -projects[i][1])
            i += 1
        if not maxHeap: break
        w += -heapq.heappop(maxHeap)
    return w
```
**Alternative (brute force: each round, scan all affordable projects for the max profit, O(k*n)):**
```python
def findMaximizedCapital(k, w, profits, capital):
    projects = list(zip(capital, profits))
    used = [False]*len(projects)
    for _ in range(k):
        best = -1; bestIdx = -1
        for i, (c, p) in enumerate(projects):
            if not used[i] and c <= w and p > best:
                best = p; bestIdx = i
        if bestIdx == -1: break
        used[bestIdx] = True
        w += best
    return w
```
**Dry run:** with `w=0`, only project with capital `0` (profit1) is affordable → take it, `w=1`; now projects with capital≤1 (profit2, profit3) both affordable → take profit3 → `w=1+3=4`.

### 241. Trapping Rain Water II
**Problem:** 2D version of Trapping Rain Water — compute trapped volume in a height map.
**Sample I/O:** `[[1,4,3,1,3,2],[3,2,1,3,2,4],[2,3,3,2,3,1]]` → `4`
```python
import heapq
def trapRainWater(heightMap):
    rows, cols = len(heightMap), len(heightMap[0])
    visited = [[False]*cols for _ in range(rows)]
    heap = []
    for r in range(rows):
        for c in range(cols):
            if r==0 or c==0 or r==rows-1 or c==cols-1:
                heapq.heappush(heap, (heightMap[r][c], r, c))
                visited[r][c] = True
    water = 0
    while heap:
        height, r, c = heapq.heappop(heap)
        for dr, dc in [(0,1),(0,-1),(1,0),(-1,0)]:
            nr, nc = r+dr, c+dc
            if 0<=nr<rows and 0<=nc<cols and not visited[nr][nc]:
                visited[nr][nc] = True
                water += max(0, height - heightMap[nr][nc])
                heapq.heappush(heap, (max(height, heightMap[nr][nc]), nr, nc))
    return water
```
**Alternative:** iterative relaxation similar to Dijkstra without a heap — repeatedly scan all cells updating a "water level" array until it stabilizes; simpler concept but much slower (no priority ordering).
**Dry run:** border cells seed a min-heap; always expand from the lowest-height boundary cell inward, trapping `height - actualHeight` water at each newly visited interior cell → total trapped `4`.

### 242. Minimum Number of Refueling Stops
**Problem:** Min refueling stops to reach a target distance, given fuel stations along the way.
**Sample I/O:** `target=100, startFuel=10, stations=[[10,60],[20,30],[30,30],[60,40]]` → `2`
```python
import heapq
def minRefuelStops(target, startFuel, stations):
    maxHeap = []
    fuel = startFuel
    stops = 0
    i = 0
    stations.append([target, 0])
    for pos, gas in stations:
        while fuel < pos:
            if not maxHeap: return -1
            fuel += -heapq.heappop(maxHeap)
            stops += 1
        heapq.heappush(maxHeap, -gas)
    return stops
```
**Alternative (DP where dp[i] = farthest distance reachable using exactly i stops):**
```python
def minRefuelStops(target, startFuel, stations):
    n = len(stations)
    dp = [startFuel] + [0]*n
    for i, (pos, gas) in enumerate(stations):
        for t in range(i, -1, -1):
            if dp[t] >= pos:
                dp[t+1] = max(dp[t+1], dp[t]+gas)
    for t, reach in enumerate(dp):
        if reach >= target: return t
    return -1
```

### 243. Course Schedule III
**Problem:** Max number of courses you can take given each has a duration and a deadline (must finish by deadline).
**Sample I/O:** `courses=[[100,200],[200,1300],[1000,1250],[2000,3200]]` → `3`
```python
import heapq
def scheduleCourse(courses):
    courses.sort(key=lambda c: c[1])
    maxHeap = []
    time = 0
    for duration, deadline in courses:
        heapq.heappush(maxHeap, -duration)
        time += duration
        if time > deadline:
            time += heapq.heappop(maxHeap)  # remove longest course taken so far
    return len(maxHeap)
```

### 244. Employee Free Time
**Problem:** Given each employee's working intervals, find the common free time across all employees.
**Sample I/O:** `schedule=[[[1,2],[5,6]],[[1,3]],[[4,10]]]` → `[[3,4]]`
```python
def employeeFreeTime(schedule):
    intervals = sorted([iv for emp in schedule for iv in emp], key=lambda x: x[0])
    merged = [intervals[0]]
    for start, end in intervals[1:]:
        if start <= merged[-1][1]:
            merged[-1][1] = max(merged[-1][1], end)
        else:
            merged.append([start, end])
    res = []
    for i in range(1, len(merged)):
        res.append([merged[i-1][1], merged[i][0]])
    return res
```
**Alternative (min-heap merging all intervals across employees in sorted-start order, same core idea via heap instead of sort):** push all intervals into a heap keyed by start time, pop in order while tracking the running merged end, recording gaps the same way.

### 245. Sliding Window Median
**Problem:** Return the median of each sliding window of size k.
**Sample I/O:** `nums=[1,3,-1,-3,5,3,6,7], k=3` → `[1,-1,-1,3,5,6]`
```python
import heapq
from collections import defaultdict
def medianSlidingWindow(nums, k):
    small, large = [], []  # max-heap (negated), min-heap
    delayed = defaultdict(int)
    small_size = large_size = 0
    def prune(heap):
        while heap and delayed[heap[0] if heap is large else -heap[0]] > 0:
            elem = heap[0] if heap is large else -heap[0]
            delayed[elem] -= 1
            heapq.heappop(heap)
    res = []
    for i, n in enumerate(nums):
        if not small or n <= -small[0]:
            heapq.heappush(small, -n); small_size += 1
        else:
            heapq.heappush(large, n); large_size += 1
        if small_size > large_size + 1:
            heapq.heappush(large, -heapq.heappop(small)); small_size -= 1; large_size += 1
        elif large_size > small_size:
            heapq.heappush(small, -heapq.heappop(large)); large_size -= 1; small_size += 1
        if i >= k-1:
            median = -small[0] if k%2 else (-small[0]+large[0])/2
            res.append(median)
            outNum = nums[i-k+1]
            delayed[outNum] += 1
            if outNum <= -small[0]: small_size -= 1
            else: large_size -= 1
            prune(small); prune(large)
    return res
```
**Alternative (maintain a sorted list via `bisect.insort`/`bisect.bisect` for the current window, O(k) per slide but much simpler):**
```python
import bisect
def medianSlidingWindow(nums, k):
    window = sorted(nums[:k])
    res = []
    def getMedian():
        mid = k//2
        return window[mid] if k%2 else (window[mid-1]+window[mid])/2
    res.append(getMedian())
    for i in range(k, len(nums)):
        window.pop(bisect.bisect_left(window, nums[i-k]))
        bisect.insort(window, nums[i])
        res.append(getMedian())
    return res
```
**Dry run:** window `[1,3,-1]` sorted → `[-1,1,3]`, median `1`; slide to `[3,-1,-3]` sorted → `[-3,-1,3]`, median `-1`; continues sliding, tracking median at each step.

### 246. Substring with Concatenation of All Words
**Problem:** Find all starting indices where a substring is exactly a concatenation of all given words (each used once, any order).
**Sample I/O:** `s="barfoothefoobarman", words=["foo","bar"]` → `[0,9]`
```python
from collections import Counter
def findSubstring(s, words):
    if not words: return []
    wordLen = len(words[0])
    totalLen = wordLen * len(words)
    wordCount = Counter(words)
    res = []
    for i in range(len(s) - totalLen + 1):
        seen = Counter()
        j = i
        while j < i + totalLen:
            word = s[j:j+wordLen]
            if word not in wordCount: break
            seen[word] += 1
            if seen[word] > wordCount[word]: break
            j += wordLen
        else:
            res.append(i)
    return res
```
**Alternative (sliding window per starting offset 0..wordLen-1, maintaining a running window count instead of rechecking from scratch each start index — reduces overall complexity):** for each of the `wordLen` possible alignments, slide a window of `len(words)` words at a time, adding/removing one word-chunk per step and comparing counts incrementally.
**Dry run:** at `i=0`: `"bar"`+`"foo"` matches both words exactly once → valid start; at `i=9`: `"foo"`+`"bar"` also matches → valid start → `[0,9]`.

### 247. Longest Substring with At Least K Repeating Characters
**Problem:** Longest substring where every character appears at least k times.
**Sample I/O:** `s="aaabb", k=3` → `3` (`"aaa"`)
```python
def longestSubstring(s, k):
    if not s: return 0
    for c in set(s):
        if s.count(c) < k:
            return max(longestSubstring(sub, k) for sub in s.split(c))
    return len(s)
```
**Alternative (sliding window over a fixed number of distinct characters, tried for each possible distinct-count 1..26):**
```python
def longestSubstring(s, k):
    best = 0
    for numUnique in range(1, 27):
        count = {}
        l = 0
        unique = countAtLeastK = 0
        for r, c in enumerate(s):
            count[c] = count.get(c, 0) + 1
            if count[c] == 1: unique += 1
            if count[c] == k: countAtLeastK += 1
            while unique > numUnique:
                left_c = s[l]
                if count[left_c] == k: countAtLeastK -= 1
                count[left_c] -= 1
                if count[left_c] == 0: unique -= 1
                l += 1
            if unique == numUnique and unique == countAtLeastK:
                best = max(best, r-l+1)
    return best
```

### 248. Count Number of Nice Subarrays
**Problem:** Count subarrays containing exactly k odd numbers.
**Sample I/O:** `nums=[1,1,2,1,1], k=3` → `2`
```python
def numberOfSubarrays(nums, k):
    def atMostK(k):
        l = 0
        oddCount = 0
        res = 0
        for r, n in enumerate(nums):
            if n % 2: oddCount += 1
            while oddCount > k:
                if nums[l] % 2: oddCount -= 1
                l += 1
            res += r-l+1
        return res
    return atMostK(k) - atMostK(k-1)
```
**Alternative (direct sliding window tracking positions of odd numbers explicitly, computing gaps between consecutive odds):** record indices of all odd numbers, then for each valid window of k consecutive odd indices, count how many ways to extend left/right into adjacent even runs — avoids the "atMostK subtraction" trick.

### 250. (Capstone) Design a Rate Limiter / LFU Cache Hybrid — synthesis exercise
Rather than one more isolated LeetCode problem, treat #250 as a synthesis checkpoint: **LFU Cache**.
**Problem:** Design a cache evicting the Least Frequently Used item (ties broken by least recently used).
**Sample I/O:** `capacity=2`; put(1,1); put(2,2); get(1)→1; put(3,3) evicts key2 (freq1, LRU among freq1); get(2)→-1; get(3)→3
```python
from collections import defaultdict, OrderedDict
class LFUCache:
    def __init__(self, capacity):
        self.cap = capacity
        self.minFreq = 0
        self.keyToVal = {}
        self.keyToFreq = {}
        self.freqToKeys = defaultdict(OrderedDict)
    def _bump(self, key):
        freq = self.keyToFreq[key]
        del self.freqToKeys[freq][key]
        if not self.freqToKeys[freq] and freq == self.minFreq:
            self.minFreq += 1
        self.keyToFreq[key] = freq+1
        self.freqToKeys[freq+1][key] = None
    def get(self, key):
        if key not in self.keyToVal: return -1
        self._bump(key)
        return self.keyToVal[key]
    def put(self, key, value):
        if self.cap == 0: return
        if key in self.keyToVal:
            self.keyToVal[key] = value
            self._bump(key)
            return
        if len(self.keyToVal) >= self.cap:
            evictKey, _ = self.freqToKeys[self.minFreq].popitem(last=False)
            del self.keyToVal[evictKey]
            del self.keyToFreq[evictKey]
        self.keyToVal[key] = value
        self.keyToFreq[key] = 1
        self.freqToKeys[1][key] = None
        self.minFreq = 1
```
**Alternative (simpler but slower: store `(freq, lastUsedTime)` per key in a dict, scan for eviction candidate on every put — O(n) eviction instead of O(1)):**
```python
import time
class LFUCache:
    def __init__(self, capacity):
        self.cap = capacity
        self.data = {}  # key -> [value, freq, order]
        self.counter = 0
    def get(self, key):
        if key not in self.data: return -1
        self.data[key][1] += 1
        self.counter += 1
        self.data[key][2] = self.counter
        return self.data[key][0]
    def put(self, key, value):
        if self.cap == 0: return
        if key in self.data:
            self.data[key][0] = value
            self.get(key)
            return
        if len(self.data) >= self.cap:
            evict = min(self.data, key=lambda k: (self.data[k][1], self.data[k][2]))
            del self.data[evict]
        self.counter += 1
        self.data[key] = [value, 1, self.counter]
```
**Dry run:** put(1,1),put(2,2) both at freq1; get(1) bumps key1 to freq2; put(3,3) needs eviction — minFreq is 1, and key2 is the only one left at freq1 → key2 evicted; get(2) → `-1`; get(3) → `3`.
