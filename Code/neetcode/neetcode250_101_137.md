## SECTION 13: 1-D Dynamic Programming

### 101. Climbing Stairs
**Problem:** n steps; can climb 1 or 2 at a time. How many distinct ways to reach the top?
**Sample I/O:** `n=3` → `3` (`1+1+1, 1+2, 2+1`)
```python
def climbStairs(n):
    if n <= 2: return n
    a, b = 1, 2
    for _ in range(3, n+1):
        a, b = b, a+b
    return b
```
**Alternative (recursive with memo):**
```python
def climbStairs(n, memo={}):
    if n <= 2: return n
    if n in memo: return memo[n]
    memo[n] = climbStairs(n-1, memo) + climbStairs(n-2, memo)
    return memo[n]
```
**Dry run:** `a=1,b=2` (n=1,2); step 3: `a,b = 2,3` → return `3`.

### 102. Min Cost Climbing Stairs
**Problem:** Pay `cost[i]` to step off stair i; can start at index 0 or 1; find min cost to reach top.
**Sample I/O:** `cost=[10,15,20]` → `15`
```python
def minCostClimbingStairs(cost):
    n = len(cost)
    dp = [0]*(n+1)
    for i in range(2, n+1):
        dp[i] = min(dp[i-1]+cost[i-1], dp[i-2]+cost[i-2])
    return dp[n]
```
**Alternative (two rolling variables, O(1) space):**
```python
def minCostClimbingStairs(cost):
    a, b = 0, 0
    for i in range(2, len(cost)+1):
        a, b = b, min(b+cost[i-1], a+cost[i-2])
    return b
```
**Dry run:** start at index 1 (cost 15), step directly to top (2 steps away) → total `15`, cheaper than starting at 0.

### 103. House Robber
**Problem:** Max sum of non-adjacent elements (can't rob two adjacent houses).
**Sample I/O:** `[1,2,3,1]` → `4` (rob houses 1 and 4, i.e. values 1 and... actually rob index0+index2: `1+3=4`)
```python
def rob(nums):
    rob1, rob2 = 0, 0
    for n in nums:
        rob1, rob2 = rob2, max(rob2, rob1+n)
    return rob2
```
**Alternative (explicit DP array):**
```python
def rob(nums):
    dp = [0]*(len(nums)+1)
    dp[1] = nums[0]
    for i in range(2, len(nums)+1):
        dp[i] = max(dp[i-1], dp[i-2]+nums[i-1])
    return dp[-1]
```
**Dry run:** rolling pair progresses `(0,1)→(1,2)→(2,4)→(4,4)`; final `rob2=4`.

### 104. House Robber II
**Problem:** Same as House Robber but houses are arranged in a circle (first and last are adjacent).
**Sample I/O:** `[2,3,2]` → `3`
```python
def rob(nums):
    if len(nums) == 1: return nums[0]
    def robLine(houses):
        rob1, rob2 = 0, 0
        for n in houses:
            rob1, rob2 = rob2, max(rob2, rob1+n)
        return rob2
    return max(robLine(nums[1:]), robLine(nums[:-1]))
```
**Alternative:** run the same linear DP three times (excluding first, excluding last, excluding both) and take the max — redundant third case but conceptually simpler to explain.
**Dry run:** exclude last (`[2,3]`)→max is `3`; exclude first (`[3,2]`)→max is `3`; overall max `3`.

### 105. Longest Palindromic Substring
**Problem:** Return the longest palindromic substring.
**Sample I/O:** `"babad"` → `"bab"` (or `"aba"`)
```python
def longestPalindrome(s):
    res = ""
    for i in range(len(s)):
        # odd length, centered at i
        l, r = i, i
        while l >= 0 and r < len(s) and s[l] == s[r]:
            if r-l+1 > len(res): res = s[l:r+1]
            l -= 1; r += 1
        # even length, centered between i, i+1
        l, r = i, i+1
        while l >= 0 and r < len(s) and s[l] == s[r]:
            if r-l+1 > len(res): res = s[l:r+1]
            l -= 1; r += 1
    return res
```
**Alternative (DP table, O(n^2) space):**
```python
def longestPalindrome(s):
    n = len(s)
    dp = [[False]*n for _ in range(n)]
    start, maxLen = 0, 1
    for i in range(n): dp[i][i] = True
    for length in range(2, n+1):
        for i in range(n-length+1):
            j = i+length-1
            if s[i]==s[j] and (length==2 or dp[i+1][j-1]):
                dp[i][j] = True
                if length > maxLen: start, maxLen = i, length
    return s[start:start+maxLen]
```
**Dry run:** expanding around center index 1 (`'a'`) grows to `"bab"` (indices 0-2) since `s[0]==s[2]=='b'` → longest found is `"bab"`.

### 106. Palindromic Substrings
**Problem:** Count how many substrings are palindromes.
**Sample I/O:** `"abc"` → `3` | `"aaa"` → `6`
```python
def countSubstrings(s):
    count = 0
    def expand(l, r):
        nonlocal count
        while l >= 0 and r < len(s) and s[l] == s[r]:
            count += 1
            l -= 1; r += 1
    for i in range(len(s)):
        expand(i, i)
        expand(i, i+1)
    return count
```
**Alternative (DP table marking all palindromic substrings, then count True entries):** build the same `dp[i][j]` table as problem 105 and sum up all `True` cells.
**Dry run:** `"aaa"`: odd centers give 3 single-char + 1 length-3 (`"aaa"`); even centers give 2 length-2 (`"aa"`,`"aa"`) → total `3+1+2=6`.

### 107. Decode Ways
**Problem:** Count ways to decode a digit string where 'A'=1...'Z'=26.
**Sample I/O:** `"226"` → `3` (`"2 2 6", "22 6", "2 26"`)
```python
def numDecodings(s):
    dp = {len(s): 1}
    for i in range(len(s)-1, -1, -1):
        if s[i] == '0': dp[i] = 0
        else:
            dp[i] = dp[i+1]
            if i+1 < len(s) and (s[i]=='1' or (s[i]=='2' and s[i+1] in '0123456')):
                dp[i] += dp[i+2]
    return dp[0]
```
**Alternative (rolling variables, O(1) space, forward direction):**
```python
def numDecodings(s):
    if s[0] == '0': return 0
    two_back, one_back = 1, 1
    for i in range(1, len(s)):
        current = 0
        if s[i] != '0': current = one_back
        two_digit = int(s[i-1:i+1])
        if 10 <= two_digit <= 26: current += two_back
        two_back, one_back = one_back, current
    return one_back
```
**Dry run:** `"226"`: from the back, `dp[3]=1`; `dp[2]` ('6')=`dp[3]=1`; `dp[1]` ('2', pairs with '6'→26 valid)=`dp[2]+dp[3]=1+1=2`; `dp[0]` ('2', pairs with '2'→22 valid)=`dp[1]+dp[2]=2+1=3`.

### 108. Coin Change
**Problem:** Fewest coins to make up an amount (unlimited supply of each denomination).
**Sample I/O:** `coins=[1,2,5], amount=11` → `3` (`5+5+1`)
```python
def coinChange(coins, amount):
    dp = [float('inf')] * (amount+1)
    dp[0] = 0
    for a in range(1, amount+1):
        for c in coins:
            if a-c >= 0:
                dp[a] = min(dp[a], 1+dp[a-c])
    return dp[amount] if dp[amount] != float('inf') else -1
```
**Alternative (BFS over amounts, treats each amount as a graph node):**
```python
from collections import deque
def coinChange(coins, amount):
    if amount == 0: return 0
    visited = {0}
    q = deque([(0, 0)])
    while q:
        amt, steps = q.popleft()
        for c in coins:
            nxt = amt + c
            if nxt == amount: return steps+1
            if nxt < amount and nxt not in visited:
                visited.add(nxt); q.append((nxt, steps+1))
    return -1
```
**Dry run:** `dp[11]` builds from smaller amounts; using `5+5+1` gives `dp[11]=3`, the minimum found.

### 109. Maximum Product Subarray
**Problem:** Contiguous subarray with the largest product.
**Sample I/O:** `[2,3,-2,4]` → `6`
```python
def maxProduct(nums):
    res = nums[0]
    curMin, curMax = 1, 1
    for n in nums:
        vals = (n, n*curMax, n*curMin)
        curMax, curMin = max(vals), min(vals)
        res = max(res, curMax)
    return res
```
**Alternative (brute force O(n^2)):**
```python
def maxProduct(nums):
    best = nums[0]
    for i in range(len(nums)):
        prod = 1
        for j in range(i, len(nums)):
            prod *= nums[j]
            best = max(best, prod)
    return best
```
**Dry run:** track both max and min (since negatives flip sign); `[2,3,-2,4]`: after `2,3` curMax=6; after `-2` flips to curMin path; after `4`, curMax stays best at `6`.

### 110. Word Break
**Problem:** Determine if a string can be segmented into words from a dictionary.
**Sample I/O:** `s="leetcode", wordDict=["leet","code"]` → `True`
```python
def wordBreak(s, wordDict):
    wordSet = set(wordDict)
    dp = [False]*(len(s)+1)
    dp[len(s)] = True
    for i in range(len(s)-1, -1, -1):
        for w in wordDict:
            if i+len(w) <= len(s) and s[i:i+len(w)] == w:
                dp[i] = dp[i] or dp[i+len(w)]
                if dp[i]: break
    return dp[0]
```
**Alternative (BFS/DFS with memoization over start indices):**
```python
def wordBreak(s, wordDict):
    wordSet = set(wordDict)
    memo = {}
    def dfs(i):
        if i == len(s): return True
        if i in memo: return memo[i]
        for j in range(i+1, len(s)+1):
            if s[i:j] in wordSet and dfs(j):
                memo[i] = True; return True
        memo[i] = False
        return False
    return dfs(0)
```
**Dry run:** `dp[8]=True` (end); `dp[4]` checks `"code"` matches `s[4:8]` and `dp[8]` is True → `dp[4]=True`; `dp[0]` checks `"leet"` matches `s[0:4]` and `dp[4]` True → `dp[0]=True`.

### 111. Longest Increasing Subsequence
**Problem:** Length of the longest strictly increasing subsequence.
**Sample I/O:** `[10,9,2,5,3,7,101,18]` → `4` (`2,3,7,101` or similar)
```python
def lengthOfLIS(nums):
    dp = [1]*len(nums)
    for i in range(len(nums)-1, -1, -1):
        for j in range(i+1, len(nums)):
            if nums[i] < nums[j]:
                dp[i] = max(dp[i], 1+dp[j])
    return max(dp)
```
**Alternative (binary search + patience sorting, O(n log n)):**
```python
import bisect
def lengthOfLIS(nums):
    tails = []
    for n in nums:
        idx = bisect.bisect_left(tails, n)
        if idx == len(tails): tails.append(n)
        else: tails[idx] = n
    return len(tails)
```
**Dry run:** `tails` evolves: `[10]→[9]→[2]→[2,5]→[2,3]→[2,3,7]→[2,3,7,101]→[2,3,7,18]` → length `4`.

### 112. Partition Equal Subset Sum
**Problem:** Determine if array can be split into two subsets with equal sum.
**Sample I/O:** `[1,5,11,5]` → `True` (`[11]` and `[1,5,5]`)
```python
def canPartition(nums):
    total = sum(nums)
    if total % 2: return False
    target = total // 2
    dp = {0}
    for n in nums:
        newDp = set()
        for t in dp:
            newDp.add(t+n)
            newDp.add(t)
        dp = newDp
    return target in dp
```
**Alternative (boolean DP array of size target+1, classic 0/1 knapsack):**
```python
def canPartition(nums):
    total = sum(nums)
    if total % 2: return False
    target = total // 2
    dp = [False]*(target+1)
    dp[0] = True
    for n in nums:
        for t in range(target, n-1, -1):
            dp[t] = dp[t] or dp[t-n]
    return dp[target]
```
**Dry run:** target = `11`; reachable sums set grows to include `11` (via `11` alone) → `True`.

### 113. Unique Paths
**Problem:** Count paths from top-left to bottom-right of an m×n grid, moving only right/down.
**Sample I/O:** `m=3, n=7` → `28`
```python
def uniquePaths(m, n):
    row = [1]*n
    for _ in range(m-1):
        newRow = [1]*n
        for c in range(n-2, -1, -1):
            newRow[c] = newRow[c+1] + row[c]
        row = newRow
    return row[0]
```
**Alternative (combinatorics formula: C(m+n-2, m-1)):**
```python
from math import comb
def uniquePaths(m, n):
    return comb(m+n-2, m-1)
```
**Dry run:** row-by-row DP: bottom row all 1's; each cell = right neighbor + below neighbor; final top-left accumulates to `28`.

### 114. Longest Common Subsequence
**Problem:** Length of the longest subsequence common to both strings.
**Sample I/O:** `text1="abcde", text2="ace"` → `3`
```python
def longestCommonSubsequence(text1, text2):
    m, n = len(text1), len(text2)
    dp = [[0]*(n+1) for _ in range(m+1)]
    for i in range(m-1, -1, -1):
        for j in range(n-1, -1, -1):
            if text1[i] == text2[j]:
                dp[i][j] = 1 + dp[i+1][j+1]
            else:
                dp[i][j] = max(dp[i+1][j], dp[i][j+1])
    return dp[0][0]
```
**Alternative (top-down recursion with memo dict keyed by (i,j)):**
```python
def longestCommonSubsequence(text1, text2):
    memo = {}
    def dfs(i, j):
        if i == len(text1) or j == len(text2): return 0
        if (i,j) in memo: return memo[(i,j)]
        if text1[i] == text2[j]:
            memo[(i,j)] = 1 + dfs(i+1, j+1)
        else:
            memo[(i,j)] = max(dfs(i+1,j), dfs(i,j+1))
        return memo[(i,j)]
    return dfs(0, 0)
```
**Dry run:** matching chars `a,c,e` line up in order within both strings → LCS length `3`.

### 115. Best Time to Buy and Sell Stock with Cooldown
**Problem:** Max profit with unlimited transactions, but must wait one day (cooldown) after selling before buying again.
**Sample I/O:** `[1,2,3,0,2]` → `3`
```python
def maxProfit(prices):
    hold, sold, rest = float('-inf'), 0, 0
    for p in prices:
        prevSold = sold
        sold = hold + p
        hold = max(hold, rest - p)
        rest = max(rest, prevSold)
    return max(sold, rest)
```
**Alternative (explicit state-machine DP table with 3 states per day):**
```python
def maxProfit(prices):
    n = len(prices)
    if n == 0: return 0
    hold = [0]*n; sold = [0]*n; rest = [0]*n
    hold[0] = -prices[0]
    for i in range(1, n):
        hold[i] = max(hold[i-1], rest[i-1]-prices[i])
        sold[i] = hold[i-1] + prices[i]
        rest[i] = max(rest[i-1], sold[i-1])
    return max(sold[-1], rest[-1])
```
**Dry run:** buy at 1, sell at 3 (profit 2), cooldown at index3 (price 0), buy again at 0, sell at 2 (profit 2) — but overlapping windows resolve via DP to optimum `3` (buy@1 sell@3 hold-cooldown-buy@0 sell@2 → total `2+2=4`? Actual answer is `3`: buy@1,sell@2(profit1),cooldown,buy@0,sell@2(profit2) → engine finds best combo `3`.

### 116. Coin Change II

```python
def change(amount, coins):
    dp = [0]*(amount+1)
    dp[0] = 1
    for c in coins:
        for a in range(c, amount+1):
            dp[a] += dp[a-c]
    return dp[amount]
```
**Alternative (2D DP table indexed by coin and amount, clearer but more memory):**
```python
def change(amount, coins):
    n = len(coins)
    dp = [[0]*(amount+1) for _ in range(n+1)]
    for i in range(n+1): dp[i][0] = 1
    for i in range(1, n+1):
        for a in range(1, amount+1):
            dp[i][a] = dp[i-1][a]
            if a >= coins[i-1]: dp[i][a] += dp[i][a-coins[i-1]]
    return dp[n][amount]
```
**Dry run:** combos for 5 using {1,2,5}: `5`; `2+2+1`; `2+1+1+1`; `1*5` → `4` total.

### 117. Target Sum
**Problem:** Assign +/- to each number to reach target sum; count ways.
**Sample I/O:** `nums=[1,1,1,1,1], target=3` → `5`
```python
def findTargetSumWays(nums, target):
    dp = {0: 1}
    for n in nums:
        newDp = {}
        for total, count in dp.items():
            newDp[total+n] = newDp.get(total+n, 0) + count
            newDp[total-n] = newDp.get(total-n, 0) + count
        dp = newDp
    return dp.get(target, 0)
```
**Alternative:** reframe as subset-sum (`P - N = target`, `P + N = sum(nums)` → `P = (target+sum)/2`), then count subsets summing to `P` via 0/1 knapsack DP — avoids the negative-key dictionary approach.

### 118. Interleaving String
**Problem:** Check if `s3` is formed by interleaving `s1` and `s2` (preserving relative order).
**Sample I/O:** `s1="aabcc", s2="dbbca", s3="aadbbcbcac"` → `True`
```python
def isInterleave(s1, s2, s3):
    if len(s1)+len(s2) != len(s3): return False
    dp = {}
    def dfs(i, j):
        if i == len(s1) and j == len(s2): return True
        if (i,j) in dp: return dp[(i,j)]
        res = False
        if i < len(s1) and s1[i] == s3[i+j]:
            res = dfs(i+1, j)
        if not res and j < len(s2) and s2[j] == s3[i+j]:
            res = dfs(i, j+1)
        dp[(i,j)] = res
        return res
    return dfs(0, 0)
```
**Alternative (bottom-up 2D boolean table):**
```python
def isInterleave(s1, s2, s3):
    m, n = len(s1), len(s2)
    if m+n != len(s3): return False
    dp = [[False]*(n+1) for _ in range(m+1)]
    dp[m][n] = True
    for i in range(m, -1, -1):
        for j in range(n, -1, -1):
            if i < m and s1[i] == s3[i+j] and dp[i+1][j]: dp[i][j] = True
            if j < n and s2[j] == s3[i+j] and dp[i][j+1]: dp[i][j] = True
    return dp[0][0]
```
**Dry run:** at each position, try consuming next char from `s1` or `s2` if it matches `s3`'s next char; a valid full interleaving path exists → `True`.

### 119. Longest Increasing Path in a Matrix
**Problem:** Longest strictly increasing path in a matrix, moving 4-directionally.
**Sample I/O:** `[[9,9,4],[6,6,8],[2,1,1]]` → `4` (path `1→2→6→9`)
```python
def longestIncreasingPath(matrix):
    rows, cols = len(matrix), len(matrix[0])
    memo = {}
    def dfs(r, c):
        if (r,c) in memo: return memo[(r,c)]
        best = 1
        for dr, dc in [(0,1),(0,-1),(1,0),(-1,0)]:
            nr, nc = r+dr, c+dc
            if 0<=nr<rows and 0<=nc<cols and matrix[nr][nc] > matrix[r][c]:
                best = max(best, 1+dfs(nr,nc))
        memo[(r,c)] = best
        return best
    return max(dfs(r,c) for r in range(rows) for c in range(cols))
```
**Alternative (topological-sort style: process cells in increasing order of value, propagating path lengths forward):** sort all cells by value ascending, then relax each cell's neighbors that have a smaller value, accumulating path length — avoids recursion.
**Dry run:** starting from `1` at (2,1), go to `2`(2,0), then `6`(1,0 or 1,1), then `9`(0,0 or 0,1) → path length `4`, the maximum found via memoized DFS.

### 120. Distinct Subsequences
**Problem:** Count distinct subsequences of `s` that equal `t`.
**Sample I/O:** `s="rabbbit", t="rabbit"` → `3`
```python
def numDistinct(s, t):
    m, n = len(s), len(t)
    dp = [[0]*(n+1) for _ in range(m+1)]
    for i in range(m+1): dp[i][n] = 1
    for i in range(m-1, -1, -1):
        for j in range(n-1, -1, -1):
            dp[i][j] = dp[i+1][j]
            if s[i] == t[j]:
                dp[i][j] += dp[i+1][j+1]
    return dp[0][0]
```
**Alternative (top-down memoized recursion, same recurrence):**
```python
def numDistinct(s, t):
    memo = {}
    def dfs(i, j):
        if j == len(t): return 1
        if i == len(s): return 0
        if (i,j) in memo: return memo[(i,j)]
        res = dfs(i+1, j)
        if s[i] == t[j]: res += dfs(i+1, j+1)
        memo[(i,j)] = res
        return res
    return dfs(0, 0)
```
**Dry run:** the three `b`'s in `"rabbbit"` give 3 ways to pick 2 of them (matching `t`'s `"bb"`) while `r,a,i,t` positions stay fixed → `3`.

### 121. Edit Distance
**Problem:** Min operations (insert/delete/replace) to convert `word1` to `word2`.
**Sample I/O:** `word1="horse", word2="ros"` → `3`
```python
def minDistance(word1, word2):
    m, n = len(word1), len(word2)
    dp = [[0]*(n+1) for _ in range(m+1)]
    for i in range(m+1): dp[i][0] = i
    for j in range(n+1): dp[0][j] = j
    for i in range(1, m+1):
        for j in range(1, n+1):
            if word1[i-1] == word2[j-1]:
                dp[i][j] = dp[i-1][j-1]
            else:
                dp[i][j] = 1 + min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1])
    return dp[m][n]
```
**Alternative (top-down recursion with memo, same recurrence, easier to trace one path at a time):** recursive `dfs(i,j)` comparing `word1[i]` vs `word2[j]`, taking `1+min(insert, delete, replace)` on mismatch, memoized on `(i,j)`.
**Dry run:** `"horse"→"ros"`: replace `h→r`, remove `o`... classic trace gives 3 edits (`horse→rorse→rose→ros`) → `3`.

### 122. Burst Balloons
**Problem:** Burst all balloons to maximize coins; bursting balloon i gives `nums[i-1]*nums[i]*nums[i+1]`.
**Sample I/O:** `[3,1,5,8]` → `167`
```python
def maxCoins(nums):
    nums = [1] + nums + [1]
    n = len(nums)
    dp = {}
    def dfs(l, r):
        if l > r: return 0
        if (l,r) in dp: return dp[(l,r)]
        best = 0
        for i in range(l, r+1):
            coins = nums[l-1]*nums[i]*nums[r+1] + dfs(l,i-1) + dfs(i+1,r)
            best = max(best, coins)
        dp[(l,r)] = best
        return best
    return dfs(1, n-2)
```
**Alternative (bottom-up interval DP, same idea iterated by increasing interval length):**
```python
def maxCoins(nums):
    nums = [1]+nums+[1]
    n = len(nums)
    dp = [[0]*n for _ in range(n)]
    for length in range(2, n):
        for l in range(0, n-length):
            r = l+length
            for i in range(l+1, r):
                dp[l][r] = max(dp[l][r], nums[l]*nums[i]*nums[r] + dp[l][i] + dp[i][r])
    return dp[0][n-1]
```
**Dry run:** think "which balloon is burst LAST in a subrange" rather than first — this lets the DP treat `nums[l-1]` and `nums[r+1]` as fixed neighbors; optimal order yields `167`.

### 123. Regular Expression Matching
**Problem:** Implement regex matching supporting `.` (any char) and `*` (zero or more of preceding element).
**Sample I/O:** `s="aa", p="a*"` → `True`
```python
def isMatch(s, p):
    memo = {}
    def dfs(i, j):
        if (i,j) in memo: return memo[(i,j)]
        if j == len(p): return i == len(s)
        match = i < len(s) and (s[i]==p[j] or p[j]=='.')
        if j+1 < len(p) and p[j+1] == '*':
            res = dfs(i, j+2) or (match and dfs(i+1, j))
        else:
            res = match and dfs(i+1, j+1)
        memo[(i,j)] = res
        return res
    return dfs(0, 0)
```
**Alternative (bottom-up 2D boolean DP table):**
```python
def isMatch(s, p):
    m, n = len(s), len(p)
    dp = [[False]*(n+1) for _ in range(m+1)]
    dp[m][n] = True
    for i in range(m, -1, -1):
        for j in range(n-1, -1, -1):
            match = i < m and (s[i]==p[j] or p[j]=='.')
            if j+1 < n and p[j+1]=='*':
                dp[i][j] = dp[i][j+2] or (match and dp[i+1][j])
            else:
                dp[i][j] = match and dp[i+1][j+1]
    return dp[0][0]
```
**Dry run:** `p="a*"` at j=0 sees `*` follows → try "skip a*" (`dfs(0,2)`, fails since s not empty) or "use one 'a', stay on same pattern position" (`dfs(1,0)`) → recursion consumes both `a`'s this way → `True`.

## SECTION 15: Greedy

### 124. Maximum Subarray
**Problem:** Contiguous subarray with the largest sum (Kadane's algorithm).
**Sample I/O:** `[-2,1,-3,4,-1,2,1,-5,4]` → `6` (`[4,-1,2,1]`)
```python
def maxSubArray(nums):
    best = nums[0]
    cur = 0
    for n in nums:
        if cur < 0: cur = 0
        cur += n
        best = max(best, cur)
    return best
```
**Alternative (Divide & Conquer, O(n log n)):**
```python
def maxSubArray(nums):
    def helper(l, r):
        if l == r: return nums[l]
        m = (l+r)//2
        leftMax = helper(l, m)
        rightMax = helper(m+1, r)
        leftSum = rightSum = float('-inf')
        s = 0
        for i in range(m, l-1, -1): s += nums[i]; leftSum = max(leftSum, s)
        s = 0
        for i in range(m+1, r+1): s += nums[i]; rightSum = max(rightSum, s)
        return max(leftMax, rightMax, leftSum+rightSum)
    return helper(0, len(nums)-1)
```
**Dry run:** running sum resets to 0 whenever negative; best window found is `4-1+2+1=6`.

### 126. Jump Game II
**Problem:** Min number of jumps to reach the last index (always assumed reachable).
**Sample I/O:** `[2,3,1,1,4]` → `2`

```python
def jump(nums):

    l = r = 0
    while r < len(nums)-1:

        l = r+1
        r = farthest
```

```python
def jump(nums):

            dp[j] = min(dp[j], dp[i]+1)
    return dp[-1]
```

### 127. Gas Station
**Problem:** Find starting gas station index to complete a circular route, or -1 if impossible.
**Sample I/O:** `gas=[1,2,3,4,5], cost=[3,4,5,1,2]` → `3`
```python
def canCompleteCircuit(gas, cost):
    if sum(gas) < sum(cost): return -1
    total, start = 0, 0
    for i in range(len(gas)):
        total += gas[i] - cost[i]
        if total < 0:
            start = i+1
            total = 0
    return start
```
**Alternative (brute force, try every starting point, O(n^2)):**
```python
def canCompleteCircuit(gas, cost):
    n = len(gas)
    for start in range(n):
        tank = 0
        traveled = 0
        for i in range(n):
            idx = (start+i) % n
            tank += gas[idx] - cost[idx]
            if tank < 0: break
            traveled += 1
        if traveled == n: return start
    return -1
```
**Dry run:** running total dips negative right after index2, resetting `start=3`; from there the total never goes negative again → answer `3`.

### 128. Hand of Straights
**Problem:** Determine if cards can be rearranged into groups of `groupSize` consecutive values.
**Sample I/O:** `hand=[1,2,3,6,2,3,4,7,8], groupSize=3` → `True`
```python
from collections import Counter
import heapq
def isNStraightHand(hand, groupSize):
    if len(hand) % groupSize != 0: return False
    count = Counter(hand)
    minHeap = list(count.keys())
    heapq.heapify(minHeap)
    while minHeap:
        first = minHeap[0]
        for c in range(first, first+groupSize):
            if c not in count: return False
            count[c] -= 1
            if count[c] == 0:
                if c != minHeap[0]: return False
                heapq.heappop(minHeap)
    return True
```
**Alternative (sort + greedy consume using a Counter, no heap):**
```python
from collections import Counter
def isNStraightHand(hand, groupSize):
    if len(hand) % groupSize: return False
    count = Counter(hand)
    for start in sorted(count):
        need = count[start]
        if need > 0:
            for c in range(start, start+groupSize):
                if count[c] < need: return False
                count[c] -= need
    return True
```
**Dry run:** smallest card `1` starts a group `1,2,3`; next smallest remaining `2` starts `2,3,4`; then `6,7,8` — all consumed cleanly → `True`.

### 131. Valid Parenthesis String
**Problem:** Check if a string with `(`, `)`, and `*` (wildcard: `(`, `)`, or empty) can be valid.
**Sample I/O:** `"(*))"` → `True`
```python
def checkValidString(s):
    lo = hi = 0
    for c in s:
        if c == '(': lo += 1; hi += 1
        elif c == ')': lo -= 1; hi -= 1
        else: lo -= 1; hi += 1
        if hi < 0: return False
        lo = max(lo, 0)
    return lo == 0
```
**Alternative (DP over (index, open-count) reachable states, memoized recursion):**

```python
    memo = {}
    def dfs(i, openCount):
        if openCount < 0: return False
        if i == len(s): return openCount == 0
        if (i, openCount) in memo: return memo[(i, openCount)]
        res = False
        if s[i] == '(': res = dfs(i+1, openCount+1)
        elif s[i] == ')': res = dfs(i+1, openCount-1)
        else: res = dfs(i+1, openCount+1) or dfs(i+1, openCount-1) or dfs(i+1, openCount)
        memo[(i, openCount)] = res
        return res
    return dfs(0, 0)
```

### 133. Merge Intervals
**Problem:** Merge all overlapping intervals.
**Sample I/O:** `[[1,3],[2,6],[8,10],[15,18]]` → `[[1,6],[8,10],[15,18]]`

```python
def merge(intervals):
    intervals.sort(key=lambda x: x[0])
    res = [intervals[0]]
    for start, end in intervals[1:]:
        if start <= res[-1][1]:
            res[-1][1] = max(res[-1][1], end)

            res.append([start, end])
    return res
```

### 136. Meeting Rooms II
**Problem:** Minimum number of meeting rooms required to accommodate all meetings.
**Sample I/O:** `[[0,30],[5,10],[15,20]]` → `2`
```python
import heapq
def minMeetingRooms(intervals):
    intervals.sort(key=lambda x: x[0])
    heap = []  # end times of ongoing meetings
    for start, end in intervals:
        if heap and heap[0] <= start:
            heapq.heappop(heap)
        heapq.heappush(heap, end)
    return len(heap)
```
**Alternative (separate sorted start/end arrays, two-pointer sweep):**
```python
def minMeetingRooms(intervals):
    starts = sorted(i[0] for i in intervals)
    ends = sorted(i[1] for i in intervals)
    rooms = maxRooms = 0
    s = e = 0
    while s < len(starts):
        if starts[s] < ends[e]:
            rooms += 1
            maxRooms = max(maxRooms, rooms)
            s += 1
        else:
            rooms -= 1
            e += 1
    return maxRooms
```
**Dry run:** heap holds end times of active meetings; `[0,30]` pushes 30; `[5,10]`: 30>5 so no pop, push 10 → heap size 2; `[15,20]`: smallest end (10)≤15 → pop, push 20 → heap size stays 2 → answer `2`.

### 137. Minimum Interval to Include Each Query
**Problem:** For each query point, find the size of the smallest interval that contains it (or -1).
**Sample I/O:** `intervals=[[1,4],[2,4],[3,6],[4,4]], queries=[2,3,4,5]` → `[3,3,1,4]`
```python
import heapq
def minInterval(intervals, queries):
    intervals.sort()
    minHeap = []
    res = {}
    i = 0
    for q in sorted(queries):
        while i < len(intervals) and intervals[i][0] <= q:
            l, r = intervals[i]
            heapq.heappush(minHeap, (r-l+1, r))
            i += 1
        while minHeap and minHeap[0][1] < q:
            heapq.heappop(minHeap)
        res[q] = minHeap[0][0] if minHeap else -1
    return [res[q] for q in queries]
```
**Alternative (brute force: for each query, scan all intervals checking containment, track min size — O(n·m)):**
```python
def minInterval(intervals, queries):
    res = []
    for q in queries:
        best = -1
        for l, r in intervals:
            if l <= q <= r:
                size = r-l+1
                if best == -1 or size < best: best = size
        res.append(best)
    return res
```
**Dry run:** processing queries in sorted order, add intervals whose start ≤ query into a min-heap keyed by size, discard intervals whose end < query; heap top is the smallest valid interval covering that query.
